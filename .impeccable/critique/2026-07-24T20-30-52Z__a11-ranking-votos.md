## Anti-Patterns Verdict

**LLM:** Mostly earned product familiarity (flat desk, Inter, tabular-nums) — not AI kitsch. Product strangeness is the failure: three labels for one lens (Votos 2022 / % da votação / sort-by-votes).

**Deterministic scan:** `detect.mjs --json` on the four files → exit 0, `[]` (0 findings). No false positives to triage.

**Visual overlays:** Not available — `/campanha` auth gate + localhost:3000 browser allowlist blocked live injection. No user-visible overlay.

## Overall Impression

Default sort by concentration is the right product move. The biggest opportunity is one shared vocabulary so Mesa CG never wonders whether the loudest number is votes, share, or local % of válidos.

## Priority Issues

### [P1] Label / metric / sort vocabulary collision

- **Why:** Under pressure, header “Votos 2022” vs cell “% da votação” vs mobile Ordenar invites wrong comparisons.
- **Fix:** One shared term (e.g. Concentração 2022) across column, Ordenar, and primary readout; secondary = votos · Nº de 435.
- **Suggested command:** `/impeccable clarify`

### [P1] Dual-% trap still live on list → detail path

- **Why:** List shows unexplained %; detail introduces local % of válidos — disclaimer one click too late.
- **Fix:** Column hint/caption: “% da votação estadual do candidato”; keep local dominance secondary.
- **Suggested command:** `/impeccable clarify`

### [P2] Card vs table VotePositionReadout hierarchy diverge

- **Why:** Same data, different story (table prioritizes share; card is middot soup).
- **Fix:** Same stack both layouts: concentration → votos · rank.
- **Suggested command:** `/impeccable distill`

### [P2] “Praça” + engineer empty state

- **Why:** Remodel is Município; “Rode o seed…” fails closed for staff.
- **Fix:** Município language; staff-safe empty (“Sem baseline TSE neste ambiente”).
- **Suggested command:** `/impeccable harden`

### [P3] Active sort under-announced for sighted scan

- **Why:** Chevron alone is easy to miss in dense headers.
- **Fix:** Active weight + optional “Ordenado por concentração 2022…”.
- **Suggested command:** `/impeccable polish`
