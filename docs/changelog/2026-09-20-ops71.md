# OPS71 — Tornar worktree `fix` (sem argumento) driverless

`pnpm worktree fix` sem argumento agora abre a sessão sem mensagem automática (driverless), espelhando o comportamento do `plan`. `pnpm worktree fix "descrição"` continua funcionando como hoje. `pnpm worktree fix --auto` (sem bag) agora lança erro alto explicando que `--auto` exige um bag.

Arquivos afetados:

- `scripts/lib/agent-session.mjs` (linha 212): Adicionada checagem `if ((purpose === 'plan' || purpose === 'fix') && !sanitized) return null`.
- `scripts/lib/worktree.mjs` (linha 142): `assertSkillAutoSupported` agora exige `bag` para `fix` com `--auto`.
- `tests/unit/agentSession.unit.spec.ts`: Testes atualizados para cobrir `fix` sem bag → `null` e `fix --auto` sem bag → `null`.
- `tests/unit/worktree.unit.spec.ts`: Testes atualizados para exigir `bag` para `fix` com `--auto`.
