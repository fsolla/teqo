**Deploy verify destravado — escopo do espelho Google Calendar por id, não por título (2026-09-13):** o verify do deploy manual (run 34763253924, main `7ca708a3`) falhou no passo "Integration tests (full suite)" com 1 failed | 82 passed — `tests/int/googleCalendarSync.int.spec.ts` > "a cancelled event in Google cancels the confirmado activity, then the trash is cleaned" caiu nas duas tentativas do `retry: 1` (1ª `AssertionError: expected 2 to be 1` no `cleanup.deleted`; 2ª `store` ainda com 1 evento `{ id: 'teqo11' }`) e os jobs `deploy-staging`/`deploy-production` ficaram skipped, sem outage (produção permaneceu no build anterior). Causa: o escopo/limpeza do spec usava marcador de título (`{ title: { like: 'C114%' } }`, introduzido em `c69990a3`, 2026-08-11), mas no Payload 3.82 + `@payloadcms/drizzle` o `like` compila para `ILIKE '%<word>%'` por palavra (split por espaço) e o `contains` para `ILIKE '%<value>%'` (`node_modules/@payloadcms/drizzle/dist/queries/parseParams.js:183-184`, `sanitizeQueryValue.js:202-212`) — ambos CONTAINS, nunca prefixo: um UUID de fixture de outro spec embutindo o hex `c114` (case-insensitive) entrou no espelho e podia ser DELETADO pela limpeza `afterEach` do próprio spec; a colisão é rara (~29 posições hex por UUID; ~4% por arquivo/run) e ficou latente desde agosto, com a C153 adicionando 2 arquivos int (speechCatalog/speechImport) que cruzaram a probabilidade e o verify rodando a suíte int completa a cada commit. Fix (sem migration, sem código de produção): `tests/int/googleCalendarSync.int.spec.ts` passa a rastrear `ownedActivityIds: Set<number>`, `createActivity(..., { track: false })` para linhas deliberadamente alheias, `afterEach` deleta por `id: { in: [...] }`, `runSync` usa `activityWhere: { id: { in: [...ownedActivityIds] } }` e um teste de regressão novo ("a foreign title CONTAINING c114 stays out of the scope (id-scoped mirror)"), com o comentário de convenção do header corrigido; `tests/unit/codebaseConventions.unit.spec.ts` ganha o describe "int fixture scoping avoids hex title markers", que varre `tests/int` e bane `title: { like|contains: '<hex-only 3+>' }`.
