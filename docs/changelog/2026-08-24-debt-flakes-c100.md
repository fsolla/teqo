# DEBT-FLAKES-C100 — fix flakes pré-existentes do C100 (Closes #553)

Duas flaky tests do pipeline de sugestões de campanha (E11) e do maquinário de
lease de consentimento, ambas pré-existentes ao PR C100:

1. **campaignSuggestions silence review** — amostra de 10 municípios insuficiente
   sob carga paralela (P(fail) nominal 0,17%). Amostra ampliada para 30
   (P(fail) ≈ 7e-9) com mensagem de diagnóstico.

2. **testDatabaseLease concurrent ensures** — TOCTOU find→create em
   `ensureLeasedConsent` permitia 2 creates sob advisory lock extremo.
   Tornado idempotente via `INSERT … ON CONFLICT (key) DO NOTHING` +
   find, eliminando a corrida independente do lock.

Mudanças: `tests/helpers/testDatabaseLease.ts`,
`tests/int/campaignSuggestions.int.spec.ts`.
