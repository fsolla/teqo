**C165-F1 — Activity: update access fecha município nulo/fora da carteira (bypass REST) (2026-09-15):** o C165 deixou o guard de **valor** do município só na server action; uma escrita direta no Local API/REST com JWT de campanha (`overrideAccess: false`) escapava do `Where` de linha de `canUpdateActivity` e gravava `municipality: null` ou um id fora da carteira. O collection access agora é `data`-aware: para advisor, `data.municipality` presente e `null`/malformado → `false`; fora do escopo quando `editing: 'carteira'` → `false` (ids via `getAccessibleMunicipalityIds`, memoizado — a carteira de leitura é a fronteira de escrita e o `Where` de linha reusa os mesmos ids, sem query extra); `editing: 'tudo'` continua repontando qualquer município, mas limpar segue coordenação/candidato-only; chave ausente mantém o `Where` de linha intacto (editar outro campo não muda). A action mantém o guard/UX (defesa em profundidade, sem mensagem nova). Sem migration, sem Consent, sem UI.
