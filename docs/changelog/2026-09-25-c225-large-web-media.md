**C225-large — ingestion of web media above 2 GiB (2026-09-25):** the web-speech ingestion no longer asks the Payload local API to `fs.readFile` an arbitrarily large artifact. Added `@aws-sdk/client-s3`/`@aws-sdk/lib-storage` as runtime dependencies plus unit coverage for the multipart seam and integration coverage for the row metadata path.
