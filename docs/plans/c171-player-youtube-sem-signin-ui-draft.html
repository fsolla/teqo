UI draft — Acervo: player do YouTube sem beco de signin (C171)

A assessoria abre a fala com vídeo no YouTube e o player pede login; a outra janela já está logada e nada muda. Este rascunho valida a saída: o vídeo toca quando o YouTube deixa e, quando não deixa, a página oferece em um clique uma superfície que toca ("Assistir na Câmara") ou "Abrir no YouTube" no ponto exato.

Cinza = estrutura existente · âmbar = novo neste item · barras cinza = conteúdo não especificado. Cenas estáticas: sem interação, sem dados reais.
