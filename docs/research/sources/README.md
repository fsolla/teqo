# Fila de fontes — pause-and-fetch

Depósito de obras centrais sem texto integral em acesso aberto. Coloque cada obra (PDF/EPUB/Markdown, obtida legalmente) em `docs/research/sources/<slug>/` e avise no chat. Binários são gitignored; apenas `README.md`/`NOTES.md` versionam.

Status: `solicitado` → `recebido` → `lido` (incorporado ao compêndio).
